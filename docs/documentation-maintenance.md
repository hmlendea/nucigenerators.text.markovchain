# Documentation maintenance

## Ownership

- Maintained by repository owner (Horațiu Mlendea)
- Contributions welcome via pull requests

## Update triggers

Update documentation when:
- Public API changes (constructors, methods, properties)
- Behavior changes (generation algorithm, validation, fallback)
- New features added
- Dependencies updated
- Test coverage changes

## Review process

1. Code changes include doc updates in same PR
2. Reviewer verifies docs match implementation
3. `docs/INDEX.md` last reviewed date updated
